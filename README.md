# Anand Vihar Co-op. Hsg. Society Ltd. — Members Portal

Login-protected portal for members and the Managing Committee of Anand Vihar CHS Ltd., Dombivli (West).

This repository holds only the website code. All society data (members, notices, NOCs, meetings, documents, activity log) is stored in Supabase and is readable only after login, under database rules that limit each member to their own flat.
